# 용어집

> 문서 전반에서 사용하는 용어입니다. 영문 알파벳 순서로 정렬되어 있습니다.

| 용어 | 의미 |
|---|---|
| **Admin API** | 프록시의 `/admin/*` 엔드포인트(섹션, 컨트랙트)입니다. 관리자 토큰과 `ADMIN_ALLOWED_IPS`에 포함된 주소가 필요합니다. chainlens의 관리자 페이지와 Ansible이 사용합니다 |
| **Admin token** (관리자 토큰) | Admin API와 chainlens 관리자 페이지용 비밀 값입니다. 운영자 머신의 `ansible/state/secrets/`(`proxy_admin_token`, `chainlens_deploy_token`)에 있습니다 |
| **Ansible phases** (Ansible 단계) | `ansible/`에 있는 번호가 매겨진 플레이북 `00`–`14`입니다(호스트, 이미지, MPC, 코디네이터, Besu, 프록시, HA, 점검, 모니터링, 백업). 단계 `01`은 코드를 호스트에 복사하며, `git pull` 후 가장 먼저 실행해야 합니다 |
| **Avatar** (아바타) | **아바타 컬렉션**(`AvatarCollection.sol` 버전 4)에 있는 플랫폼의 이미지 토큰(ERC-721)이며 **아이템**입니다. 가격이 있는 그림으로, 컨트랙트 계정 센터가 민팅하고 섹션 사용자 계정이 한 번 구매하면 그 계정에 귀속됩니다. [아바타](features/avatars.md) 참조 |
| **Big / small / none pool** | MPC 키의 사전 서명 풀 등급으로, 미리 준비해 두는 사전 서명의 수입니다. `big`은 사용량이 많은 계정(SENDER01, 선지급 계정), `small`은 일반 계정, `none`은 거의 사용하지 않는 계정(느린 경로로 서명)에 사용합니다 |
| **Cold path** (콜드 경로) | 준비된 사전 서명 없이 서명하는 방식입니다. MPC 노드가 필요할 때 사전 서명을 계산합니다(밀리초 대신 약 0.6초) |
| **Consumption account** (소비 계정) | 자금을 **받는** 섹션의 계정입니다. 사용자의 +x 이체, 아이템 판매와 닉네임 레벨 업그레이드 대금을 즉시 받습니다. **취소**에 서명하고 그 환불을 지급합니다. 결제 계정으로 스윕됩니다 |
| **Contract account center** (컨트랙트 계정 센터, `CONTRACT_CENTER`) | 프록시를 통해 모든 컨트랙트를 배포하는(그리고 아바타와 닉네임을 민팅하고 그 가격과 사용자 레벨을 정하는) MPC 계정입니다. 이 계정이 배포한 컨트랙트는 ABI와 함께 체인에 등록됩니다 |
| **Coordinator** (코디네이터, coord1, coord2) | MPC 노드의 부분 서명을 결합합니다. 키 자료는 **전혀** 보유하지 않습니다. 포트 9100에서 이더리움 서명기 JSON-RPC(`eth_accounts`, `eth_sendTransaction`)를 제공합니다 |
| **Correction** (정정) | 섹션 게이트웨이가 오프라인 중에 응답하고 큐에 저장했지만, 연결이 돌아온 후 체인이 거부한 요청입니다(그사이 판매된 아이템, 새 가격, 끝난 취소 기간). 게이트웨이는 원장에서 그것을 되돌리고, 보고하며(`/gateway/report`), 애플리케이션의 `correction_webhook`으로 보냅니다. [섹션 게이트웨이](components/gateway.md#corrections) 참조 |
| **Draining** (드레이닝) | 단절 후 섹션 게이트웨이의 모드입니다. 큐를 한 번에 하나씩 순서대로 프록시에 보내며, 서명자의 논스를 점검해 두 번 보내지 않습니다. 그다음 원장을 체인과 조정하고 online이 됩니다 |
| **Floating IP / VIP** (플로팅 IP(VIP)) | keepalived가 h135와 h136 사이에서 옮기는 주소입니다. `.150`(Besu RPC, MPC 서명기)과 `.151`(프록시)이 있습니다 |
| **Gateway** (섹션 게이트웨이) | 섹션마다 애플리케이션 옆에 두는 선택적 서비스(`gateway/`, 포트 30010)입니다. 섹션 키로 프록시의 API를 제공하며, 프록시에 연결할 수 없는 동안에는 자체 원장으로 응답하고 쓰기를 큐에 저장합니다(모드: online, offline, draining). [섹션 게이트웨이](components/gateway.md) 참조 |
| **HA pair** (HA 쌍) | h135와 h136입니다. 애플리케이션 경로의 모든 것이 두 호스트 모두에서 실행되며, 그중 하나가 활성입니다 |
| **Hold period** (보류 기간) | 아이템 판매(또는 닉네임 레벨 업그레이드)를 **취소**할 수 있는 기간입니다: 배포 시 `holdDays`(기본 7일), 컨트랙트의 `holdSeconds` |
| **Item** (아이템) | 아바타 또는 닉네임(`BoundItems.sol`)입니다. 센터가 민팅하고, 섹션 사용자 계정이 한 번 구매하며, 가격은 즉시 그 섹션의 소비 계정으로 지불되고, 재판매나 이전은 없으며(ERC-5192), 보류 기간 안에 취소할 수 있습니다 |
| **MPC** | 다자간 연산(Multi-party computation)입니다. 키는 3개의 MPC 노드에 3개의 **키 조각**으로 나뉩니다. 임의의 2개가 함께 서명할 수 있으며, 하나만으로는 서명할 수 없습니다. 전체 키는 어디에도 존재하지 않습니다 |
| **MPC node** (MPC 노드, mpc1–3, node 0–2) | 모든 키의 조각 하나를 보유하고, 각 트랜잭션을 자체 정책과 대조하며, 서명과 키 생성에 참여합니다. 각 노드는 별도의 팀이 운영합니다 |
| **Nickname** (닉네임) | 닉네임 컬렉션(`NicknameCollection.sol` 버전 6)에 있는 플랫폼의 이름 토큰이며 **아이템**입니다. 센터가 민팅한 이름으로 **사용자 레벨**이 있으며, 한 계정이 여러 개를 보유할 수 있습니다. [닉네임](features/nicknames.md) 참조 |
| **Nonce** (논스) | 발신자의 트랜잭션 카운터입니다. 프록시는 이를 메모리에서 추적하고(Redis는 캐시일 뿐입니다) **논스 공백**(누락된 논스가 이후 모든 트랜잭션을 막는 상태)을 복구합니다 |
| **Operator** (운영자) | Ansible을 실행하는 머신과 사람입니다(`operator_ip`). `ansible/state/`를 보유합니다 |
| **Payment account** (결제 계정) | 스윕된 자금을 모으는 섹션의 계정입니다. SENDER01로 반환됩니다 |
| **Policy** (정책) | 각 MPC 노드의 자체 규칙(chain id, 최대 금액과 가스, 허용된 수신처)입니다. 규칙을 벗어난 트랜잭션은 거부됩니다 |
| **Presignature** (사전 서명) | 미리 계산된 일회용 서명의 절반으로, 서명을 빠르게 합니다. 풀은 백그라운드에서 다시 채워집니다 |
| **Proxy** (프록시) | 애플리케이션 API(`proxy/`, 포트 30000)입니다. 한 번에 하나만 실행되며, VIP `.151` 뒤에 있습니다 |
| **QBFT** | 이 체인의 합의 방식입니다. 검증자가 4개이면 블록을 만들기 위해 3개가 온라인이어야 합니다 |
| **Registry admin** (레지스트리 관리자) | SectionRegistry(섹션, 계정, 컨트랙트)에 쓸 수 있는 MPC 계정입니다 |
| **RPC node** (RPC 노드, rpc1, rpc2) | 프록시, 코디네이터, chainlens에 JSON-RPC를 제공하는 비검증 Besu 노드입니다 |
| **Section** (섹션) | 자체 API 키, 계정, 자금 흐름을 가지며 SectionRegistry에 기록되는 비즈니스 단위입니다. [섹션](features/sections.md)을 참조하십시오 |
| **Section key** (섹션 키, `sk_…`) | 섹션의 API 키로, `X-Section-Key`로 전송합니다. 생성하거나 교체할 때 한 번만 표시됩니다 |
| **SectionRegistry** | 섹션, 섹션의 계정(사용자, 선지급, 소비, 결제, 폐기)과 등록된 컨트랙트를 기록하는 온체인 컨트랙트입니다 |
| **SENDER01** | 플랫폼의 주요 자금 보유 MPC 계정입니다. 충전 자금을 제공합니다(섹션이 없으면 새 계정과 이체 자금도 제공합니다) |
| **Share** (키 조각) | 키 중 MPC 노드 하나가 가진 부분입니다. 키 조각 하나만으로는 쓸모가 없습니다. 노드별로 매시간 백업됩니다 |
| **Spare account** (예비 계정) | 섹션 게이트웨이가 온라인일 때 미리 만들어 두는 계정입니다(3개 MPC 노드 모두 필요). 그 섹션 아래에 등록되며, 오프라인 중 `/createaccount`가 내줍니다 |
| **Stalled** (정지됨(STALLED), 노드) | 여전히 "in sync"로 보고하면서 블록 가져오기를 멈춘 Besu 노드입니다 |
| **Stalled** (정지됨(STALLED), 발신자) | 프록시에서, 발신자의 트랜잭션이 풀에 준비되어 있지만 블록이 계속 생성되는데도 포함되지 않는 상태입니다 |
| **Undo** (취소) | 보류 기간 안에 `from` 없이 `/contract/send`로 보내는 `undo` / `undoLevel`: 돈을 받은 소비 계정이 구매자에게 환불합니다(판매: 아이템에 지불한 모든 금액, 아이템은 센터로 돌아가 다시 판매; 레벨: 가장 최근 업그레이드만) |
| **Upfront account** (선지급 계정) | 자금을 **지급하는** 섹션의 계정입니다. 새 사용자 계정과 −x 이체에 자금을 제공하며, SENDER01에서 충전됩니다 |
| **User account** (사용자 계정) | 섹션이 생성한 계정(해당 키로 `/createaccount` 호출)이며, 해당 섹션에 속합니다 |
| **User level** (사용자 레벨) | 닉네임의 레벨(숫자, 이전 이름 *edge level*)입니다. 소유자가 단계 가격을 지불해 올리며(`upgradeLevel`), 취소할 때만 내려갑니다 |
| **Validator** (검증자, val1–4) | QBFT 합의에 참여하는 Besu 노드입니다. 호스트 .135–.138에 하나씩 있습니다 |
| **Version-2 collection** (버전 2 컬렉션) | 섹션 도입 이전의 이미지 컬렉션(SENDER01이 민팅)입니다. 폐기되었습니다: 프록시는 더 이상 이를 읽거나, 민팅하거나, 판매하지 않습니다. 버전 3 아바타 컬렉션(재판매 있음)은 프록시에게 일반 컨트랙트입니다 |
| **+x / −x** | 섹션 이체입니다. +x = 사용자 → 소비 계정, −x = 선지급 계정 → 사용자 |
